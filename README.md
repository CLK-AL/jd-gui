# JD-GUI

JD-GUI is a standalone graphical utility that displays Java source codes of ".class" files. You can browse the
reconstructed source code with the JD-GUI for instant access to methods and fields.

![](https://raw.githubusercontent.com/java-decompiler/jd-gui/master/src/website/img/jd-gui.png)

## Decompiler Configuration

1. Decompile jar with Vineflower on Save All Sources (Ctrl+Alt+S). Individual classes are still decompiled by JD-Core.
2. Set at org.jd.gui.service.preferencespanel.ClassFileDecompilerPreferences.decompileWithVineflower using
   org.jd.gui.service.preferencespanel.GenericPreferencesPanelProvider and
   org.jd.gui.service.preferencespanel.Preference implementations like
   org.jd.gui.service.preferencespanel.VineflowerFileSaverPreferencesProvider for
   org.jd.gui.service.preferencespanel.VineflowerFileSaverPreferences
## Additional Features

- Code Reformatted with .idea/ProjectCodeStyle.xml
- Naming convention for version YYYY.M.D (e.g., 2024.1.0)
- Preferences (Ctrl+Shift+P) of SourceSaver set to false so original line numbers and metadata are not generated by default
- Save All Sources (Ctrl+Alt+S) of a jar file named pkg.jar suggests pkg-sources.jar to comply with maven conventions
- Custom RSyntaxTextArea TokenMaker for Java 21 keyword highlighting

## How to build JD-GUI ?

```
> git clone https://github.com/java-decompiler/jd-gui.git
> cd jd-gui
> ./gradlew build 
```

generate :

- _"build/libs/jd-gui-x.y.z.jar"_
- _"build/libs/jd-gui-x.y.z-min.jar"_
- _"build/distributions/jd-gui-windows-x.y.z.zip"_
- _"build/distributions/jd-gui-osx-x.y.z.tar"_
- _"build/distributions/jd-gui-x.y.z.deb"_
- _"build/distributions/jd-gui-x.y.z.rpm"_

## How to launch JD-GUI ?

- Double-click on _"jd-gui-x.y.z.jar"_
- Double-click on _"jd-gui.exe"_ application from Windows
- Double-click on _"JD-GUI"_ application from Mac OSX
- Execute _"java -jar jd-gui-x.y.z.jar"_ or _"java -classpath jd-gui-x.y.z.jar org.jd.gui.App"_

## How to use JD-GUI ?

- Open a file with menu "File > Open File..."
- Open recent files with menu "File > Recent Files"
- Drag and drop files from your file explorer

## How to extend JD-GUI ?

```
> ./gradlew idea 
```

generate Idea Intellij project

```
> ./gradlew eclipse
```

generate Eclipse project

```
> java -classpath jd-gui-x.y.z.jar;myextension1.jar;myextension2.jar org.jd.gui.App
```

launch JD-GUI with your extensions

## How to uninstall JD-GUI ?

- Java: Delete "jd-gui-x.y.z.jar" and "jd-gui.cfg".
- Mac OSX: Drag and drop "JD-GUI" application into the trash.
- Windows: Delete "jd-gui.exe" and "jd-gui.cfg".
